# Certificate fonts

TTF files embedded (subset) into certificate PDFs by `lib/certificates/pdf.ts`. They are the
app's own typefaces, downloaded from Google Fonts, and they cover the Kazakh Cyrillic letters (Ә Ғ Қ Ң Ө Ұ Ү Һ І).

- Nunito (SemiBold 600, ExtraBold 800): SIL Open Font License 1.1, https://github.com/googlefonts/nunito
- Rubik (ExtraBold 800): SIL Open Font License 1.1, https://github.com/googlefonts/rubik
